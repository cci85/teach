填空題轉換（克漏字）

貼上填空題的純文字，自動在每個底線空格放入 Moodle 克漏字作答格；答案與配分在下方逐格填寫，產生的文字可直接貼進 Moodle「克漏字（Cloze）」題目的內容欄。

1. 貼上題目

連續三個以上的底線（___ 或全形 ＿＿＿）會變成一個作答格；題目裡沒有底線的題，會在題目最後自動補一格。新的一題以行首的題號辨識（1.、2、、(3) 等），題號後的 (2%)、（4分） 會當作該題配分。表格與圖片不處理，只保留文字。

2. 填入答案與配分

配分方式：
0
題數
0
作答格
0
尚未填答案
0
總分
貼上題目後，這裡會列出每一個作答格。

3. 克漏字文字（貼進 Moodle 題目內容）

每格輸出成 {分數:SHORTANSWER:%100%答案~%0%　　　　}；後面的 %0% 加全形空白不影響計分，只用來決定作答格寬度：題目中的底線空格（填空題）一律 4 個全形空白，題目沒有底線、在題末自動補的格（簡答題）一律 10 個全形空白；若答案本身比這更長，Moodle 會依答案長度加寬。同一格有多個可接受答案時，用 | 分隔，例如 5|五。答案中的 = ~ } # / " \ 會自動加上反斜線，學生作答時照常輸入即可。SHORTANSWER 需逐字相符才給分（不分大小寫）。Moodle 克漏字的分數須為整數；依題目配分預填時若無法整除，餘數會加在該題第一格，請自行調整。尚未填答案的格子會輸出「待填」，記得補上。
